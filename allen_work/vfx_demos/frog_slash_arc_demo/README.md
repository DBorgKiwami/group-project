# Pure Slash Arc VFX Demo

Minimal Godot 4.6 prototype for testing only the sword slash VFX. The scene intentionally avoids placeholder characters so it is not confused with the team's final protagonist or enemy design.

## Open

Open this folder in Godot:

```text
C:\Users\ASUS\Documents\Codex\2026-07-02\new-chat\outputs\frog_slash_arc_demo
```

Run the main scene. Press `Space` to trigger the slash at the center, or left-click to place a slash manually.

## What It Demonstrates

- low-resolution pixel-art presentation
- 6-frame blue slash sprite sheet
- red/blue stained-glass shard hit feedback
- neutral dark test background
- center/origin marker for trigger-position testing
- small screen shake
