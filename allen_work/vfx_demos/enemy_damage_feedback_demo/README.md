# Enemy Damage Feedback Demo

Small Godot 4.6 demo for combat feedback.

## Controls

- `Space`: enemy takes 1 damage
- `R`: reset enemy health

## What It Shows

- Enemy health uses 5 hearts, not a bar
- One hit removes one full heart
- Empty hearts stay visible
- Damage number pops up when hit
- Enemy briefly flashes red when hit

This is meant to connect later with slash arc or tongue snap attacks.
