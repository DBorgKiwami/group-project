# Combat Warning Marker Demo

Small Godot 4.6 combat warning marker prototype for the frog game.

## Direction

This demo keeps only the warning marker VFX/UI itself. It can later be placed under enemies, attack zones, or boss skills before the hit actually happens.

## Controls

- `Left / Right`: switch marker type
- `Space / E`: restart the warning pulse
- `R`: reset to circle marker

## What It Shows

- circle warning area
- line warning strip
- arc warning area
- red danger fill
- gold pixel border
- short pre-attack flashing pulse
