# Death Screen Demo

Small Godot 4.6 death screen prototype for the frog game.

## Direction

This death screen is inspired by:

- Minecraft: clear death message, cause text, retry/return choices.
- Hollow Knight: dark quiet mood, soul-like character focus.

The final theme is adjusted for our frog game: red-tinted death overlay, sinking pond mood, empty hearts, and the same character portrait used in the HUD.

## Controls

- `Left / Right`: switch selected button
- `R`: restart the small screen animation

## What It Shows

- dark pond-style background
- semi-transparent red overlay on top of the scene
- title: `YOU CROAKED!`
- HUD character portrait with red blink
- 5 empty hearts
- `Retry` and `Return` buttons
