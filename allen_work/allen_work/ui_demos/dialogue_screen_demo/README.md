# Dialogue Screen Demo

Small Godot 4.6 dialogue UI prototype for the frog game.

## Direction

This demo keeps the same pixel UI direction as the HUD, death screen, and pause screen. The dialogue box sits at the bottom of the screen so the player can still see the game scene behind it.

## Controls

- `Space / Enter / E`: go to the next dialogue page
- `R`: restart the dialogue

## What It Shows

- dim game scene behind the UI
- bottom dialogue box with brown-gold pixel frame
- speaker name plate
- character portrait area
- simple typewriter-style text reveal
- small continue arrow
