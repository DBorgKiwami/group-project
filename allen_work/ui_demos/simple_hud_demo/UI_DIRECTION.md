# Frog Game HUD Direction

## Current Focus

For now the HUD only needs to show the player portrait and health.

## Fixed HUD Elements

- Top-left: player portrait.
- Next to portrait: 5 heart health display.

## Health Rules

- Max health is 5 hearts.
- Damage removes 1 full heart each time.
- Empty hearts stay visible as dark heart shapes.
- There are no half-heart states.
- When taking damage, the portrait flashes red for a short moment.

## Visual Rules

- Keep the UI compact and readable.
- Use clear pixel shapes.
- Keep this demo to the portrait and hearts only.
