# Item Pickup Popup Demo

Small Godot 4.6 item pickup / reward popup prototype for the frog game.

## Direction

This demo keeps only the reward popup UI itself. It can later be triggered after picking up an item, opening a chest, finishing a dialogue, or receiving a quest reward.

## Controls

- `Space / E`: show the popup again
- `Left / Right`: switch reward type
- `R`: reset to the first reward

## What It Shows

- brown-gold pixel reward popup
- small item icon
- label: `FOUND`
- item names: `LILY KEY`, `WATER GEM`, `OLD CHARM`
- pop-in, short hold, and fade-out animation
