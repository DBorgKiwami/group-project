# Interaction Prompt Demo

Small Godot 4.6 interaction prompt prototype for the frog game.

## Direction

This demo keeps only the prompt UI itself, so it can be checked as a clean reusable UI piece before being placed above NPCs or objects.

## Controls

- `Left / Right`: switch prompt type
- `E / Space`: trigger a small confirm pulse
- `R`: reset the demo

## What It Shows

- small brown-gold pixel prompt box only
- key label: `E`
- action text: `Talk`, `Inspect`, `Pick Up`, `Enter`
- floating movement to show the prompt is active
