# Objective Tracker Demo

Small Godot 4.6 demo for playable demo guidance.

## Controls

- `Space / E`: move to the next objective
- `Left / Right`: preview objectives
- `R`: reset to the first objective

## What It Shows

- A small objective tracker in the top-left corner
- A short `OBJECTIVE UPDATED` popup
- Progress dots for a short playable level flow
- Pond-style background only for preview

This is meant to guide the player through a vertical slice, such as moving from the pond bank to lily pads, then to an NPC, then to the old well.
