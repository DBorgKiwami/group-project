# Screen Transition Demo

Small Godot 4.6 demo for area transition UI.

## Controls

- `Space`: replay transition
- `R`: replay transition
- `Left / Right`: switch area name

## What It Shows

- Dark pixel fade in and fade out
- Area name popup
- Small brown UI frame matching the current HUD style
- Simple pond-like background for preview only

This can be reused later when the player enters a new area, restarts a scene, or moves into a boss room.
