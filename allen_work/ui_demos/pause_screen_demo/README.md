# Pause Screen Demo

Small Godot 4.6 pause menu prototype for the frog game.

## Direction

The layout mixes Minecraft-style centered menu buttons with a quiet Hollow Knight-style dark overlay. It keeps the same brown pixel frame language as the HUD and death screen demos.

## Controls

- `Escape`: show or hide the pause menu
- `Up / Down` or `W / S`: switch option
- `Enter / Space`: select option

## What It Shows

- dim game scene underneath
- semi-transparent pause overlay
- title: `PAUSED`
- three centered options: `Resume`, `Quit Game`, `Exit Desktop`
